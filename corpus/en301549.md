# EN 301 549 European Standard Accessibility Requirements

## Clause 9.1.1.1 Non-text content
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 1.1.1 Non-text Content.

## Clause 9.2.1.2 No keyboard trap
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 2.1.2 No Keyboard Trap.

## Clause 9.2.4.3 Focus order
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 2.4.3 Focus Order.

## Clause 9.2.4.7 Focus visible
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 2.4.7 Focus Visible.

## Clause 9.3.3.1 Error identification
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 3.3.1 Error Identification.

## Clause 9.4.1.2 Name, role, value
Where ICT is a web page, it shall satisfy the WCAG 2.2 Success Criterion 4.1.2 Name, Role, Value.

## Clause 11.5 Interoperability with assistive technology
Where ICT has assistive technology software installed, the user interface elements shall expose programmatic name, role, state, and boundary coordinates over standard accessibility APIs.
